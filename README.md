# Bank Accounts

Навчальний консольний застосунок до лабораторної роботи №1
«Організація професійного Python-проєкту та Git».

## Варіант

3. Система банківських рахунків.

## Вимоги

- Python 3.11+

## Встановлення

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -e .
```

## Запуск

```powershell
python -m bank_accounts.main
```

Або після встановлення пакета:

```powershell
bank-accounts
```

## Структура проєкту

- `src/bank_accounts/models.py` — модель банківського рахунку.
- `src/bank_accounts/services.py` — бізнес-логіка операцій.
- `src/bank_accounts/main.py` — консольний інтерфейс і точка входу.
- `src/bank_accounts/exceptions.py` — власні винятки.
- `tests/` — автоматизовані перевірки.

## Функції застосунку

- перегляд усіх рахунків;
- поповнення рахунку;
- зняття коштів;
- перевірка балансу;
- пошук рахунку за номером;
- обчислення загальної суми коштів;
- сортування рахунків за балансом.
